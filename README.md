# PetCare 

Sistema de gerenciamento para pet shop, desenvolvido como um projeto parcial. O PetCare permite organizar os cadastros de animais e seus tutores, com uma interface simples para visualizar, cadastrar, editar, pesquisar e arquivar pets.

# Tecnologias que foram usadas

- Frontend: React e Vite
- Backend: Node.js e Express
- Validação: Zod
- Persistência: arquivo JSON

# Funcionalidades

- Cadastro de pets e informações dos tutores;
- Edição e consulta dos cadastros;
- Busca e filtro por espécie;
- Arquivamento e restauração de pets;
- Validação dos dados enviados;
- Interface responsiva.

# Como executar

É necessário ter o Node.js 18 ou superior instalado.
Clone o repositório e instale as dependências:

```bash
git clone https://github.com/IassOthec/pet-shop.git
cd pet-shop
npm install
```
Depois, inicie o projeto:

```bash
npm run dev
```
O frontend e o backend serão iniciados juntos:

- **Frontend:** http://localhost:5173
- **Backend:** http://localhost:3000

# Organização

O projeto está sendo dividido em duas partes:

- `frontend/` : interface e interação com o usuário.
- `backend/` : API responsável pelos cadastros e regras do sistema.
